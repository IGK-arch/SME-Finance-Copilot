- Ровно тот же набор 74 + 26, 67 EN / 33 ZH. Определения сверяются с
  `artifacts/strata-reasoning-100-comparison-20261017.json` перед запуском.

  output 2048, до 12 вызовов, 128000 суммарных токенов, 120 s на запрос и
  240 s модельного времени на сценарий — существующие бюджеты сравнения.
- Новый чистый synthetic workspace для каждого случая, прежние evaluator и grader.
  Сценарий AUDITOR сохраняет отказ до обращения к модели.
- Хеши исходников фиксируются; изменение кода останавливает очередь. Identity
  содержит фактическую модель, runtime, старт процесса, context и проверенный SHA-256 весов.
- Результат каждого сценария сразу сохраняется. Неуспех не заменяется успешным повтором.
  Зафиксированное нарушение safety assertion прерывает очередь; инфраструктурный сбой
  отмечается отдельно. Неполная серия не объявляется COMPLETED.
- Нет ручного семантического анализа в этой фазе. Автоматический grade сохраняется
  как исходное свидетельство, но не доказывает правильность свободного текста.

Квантизации Q4_K_M и UD-Q4_K_M неодинаковы; эта серия не измеряет BF16-качество.
Runtime отличается от прежней Strata. Появилась поддержка провайдера и служебная
обвязка, поэтому нельзя объявлять сравнение с предыдущей серией побитово идентичным.
Для всех пяти новых моделей фиксируется одна версия кода. Реальные скорость,
качество и число дошедших до модели случаев будут известны только из результатов.

## Подключение и защита

Граф агента → `ChatGateway(provider="llamacpp")` → локальный мост 127.0.0.1:18444
с отдельным токеном → SSH с закреплённым ключом сервера → sidecar 127.0.0.1:8082 →
llama-server 127.0.0.1:8081. `/v1/status` — собственный endpoint sidecar, не API upstream.
Sidecar проверяет `/props` native-сервера и собирает реальную Windows RAM/commit/disk
телеметрию. Управление процессами недоступно модели и HTTP-мосту.

Сохранены allowlist запросов, обязательный bridge token, запрет внешнего model URL,
лимиты ответов, строгий tool-call parser, отсутствие mock fallback, серверные проверки
доступа, независимый validator и точные OWNER approvals. Перед каждым запросом
требуется не менее 5 GiB свободной RAM и commit, 20 GiB диска; загрузчик оставляет
30 GiB диска. Веса проверяются повторно перед запуском. Никаких реальных платежей,
реальных данных, внешних уведомлений или платных inference API.

Исходная Strata остаётся активной во время загрузки. Перед серией её точные процессы
останавливаются; после завершения или обработанной ошибки очередь запускает прежнюю
конфигурацию и отдельно проверяет готовность. Внезапное выключение компьютера/сервера
может прервать эту процедуру; `restore=VERIFIED` ставится только после проверки.

Occamy, Qwen3.8 и Qwen3.6 завершили по 100 первичных случаев. Gemma остановилась
