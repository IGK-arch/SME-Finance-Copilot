# SME Finance Copilot — пакет передачи в Codex

Дата сборки: 12.10.2026. Язык ТЗ: русский. Целевой конкурсный интерфейс и материалы: английский по приложенным правилам. Все финансовые примеры — синтетические.

## Основные файлы

- `MASTER_SPEC.md` — полная спецификация и контекст, включая полные текстовые приложения R1–R3.
- `SME_Finance_Copilot_Master_Spec.docx` — оформленная Word-версия того же содержания.
- `CODEX_START_HERE.md` и `START_PROMPT.txt` — порядок чтения и готовое поручение исполнителю.
- `AGENTS.md` — проектные инструкции; при переносе в существующий repo сначала согласовать с его инструкциями.
- `contracts/` — предложенные JSON Schema, пример команды и demo policy; это не готовый продукт.
- `checklists/` — 36 инвариантов, 100 acceptance-проверок и 36 задач. Статусы изначально NOT_RUN/NOT_STARTED.
- `sources/` — оригинальные три DOCX, текстовые версии, раскрытые ссылки и изображение из ресёрча.
- `context/` — ссылки из переписки и карта переноса контекста.

## Как передавать

Распакуйте пакет рядом с проектом. Передайте Codex `START_PROMPT.txt`; дайте доступ к файлам, прежде всего `CODEX_START_HERE.md` и `MASTER_SPEC.md`. Не нужно переносить исходные DOCX в production image или отдавать исследовательские документы самому продуктовому агенту.

Это пакет требований и контекста, не реализованный Copilot. Внешние факты и текущие API при сборке не перепроверялись; источники и исторические уточнения отделены от проектных решений. SHA-256 исходных файлов находятся в `sources/manifest.json`.
