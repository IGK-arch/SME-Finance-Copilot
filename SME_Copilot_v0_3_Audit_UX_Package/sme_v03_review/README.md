# SME Finance Copilot: аудит v0.2.0 и следующая итерация

Пакет подготовлен 13 октября 2026 года по приложенному TECHNICAL_REPORT_RU.md.

## Что находится внутри

- AUDIT_AND_UX_SPEC_RU.md — разбор пробелов, целевой UX, архитектурные изменения и критерии проверки.
- CODEX_NEXT_ITERATION.md — исполнимое поручение на доработку существующего репозитория, не на переписывание продукта.
- UX_Prototype.html — автономный кликабельный дизайн-прототип. Открывается в браузере без сервера. Это визуальное предложение на демонстрационных числах, НЕ текущий кабинет, НЕ настоящий AI, НЕ банковский адаптер и НЕ доказательство готовности системы.

## Граница проверки

Исходный код приложения, raw test reports, текущие скриншоты и работающий runtime не предоставлены. Факты о реализации приведены по техническому отчёту и не являются результатами независимого запуска. Гипотезы аудита и проектные решения отмечены отдельно. Редизайн не должен отменять существующие финансовые инварианты и ограничения исполнения.
