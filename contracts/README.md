# Контракты передачи

Это предложенные структурные контракты из ТЗ, не работающий backend. Валидный JSON не доказывает полномочия, корректность денег и исполнение: нужны серверные доменные проверки.

`payment-command.schema.json` задаёт узкую команду P0 для CNY. `tool-result.schema.json` — общий конверт ответа. `plan-envelope.schema.json` — ссылки и версии плана; сам DAG и доказательства хранятся отдельными объектами. `domain-event.schema.json` — конверт события. `demo-policy.yaml` — пример ограничений для golden scenario.

Пример платежа — 90 000 CNY в минимальных единицах. Все ID фиктивные. Файлы не дают реального права совершать платежи. Политика HARD относится к условному примеру и не является нормативным требованием.

При сборке проверена синтаксическая корректность JSON Schema и соответствие примера payment-command своей схеме. Никакие финансовые API или продуктовые тесты этим не запускались.
